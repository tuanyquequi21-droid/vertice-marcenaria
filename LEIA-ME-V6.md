# Vértice Gestão V6

1. Faça backup do projeto atual.
2. No Supabase, execute SOMENTE `sql/08_ATUALIZACAO_V6_COMPLETA.sql`.
3. Substitua os arquivos do site pelos da V6 (mantenha seu `config.js` real).
4. Atualize o navegador sem cache.

A V6 é incremental e não exige reset do banco. Não execute novamente 00–07.

Regra financeira do orçamento: a margem continua usando `custo / (1 - margem)`. Em parcelamento, a taxa padrão de 9% é aplicada UMA ÚNICA VEZ sobre o preço à vista, independentemente do número de parcelas.
