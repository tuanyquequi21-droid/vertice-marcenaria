# Studio V8 — teste de projeto e ambientes

Foi criada uma demonstração HTML independente V8 a partir da V7 aprovada, com cadastro local de múltiplos ambientes e móveis, seleção de móvel para edição, duplicação, exportação JSON do projeto e CSV consolidado de peças.

**Limitações:** esta demonstração foi entregue como arquivo local na conversa e ainda não foi incorporada como aplicação web ao repositório. O editor visual continua sendo a perspectiva esquemática da V7, não uma cena de ambientes 3D. Não há sincronização com Supabase, autenticação nem publicação. Os quantitativos continuam preliminares e exigem validação de marcenaria. Sintaxe JavaScript validada com Node; teste automatizado em navegador não realizado.

Próximas ações: incorporar código testado da V8, testes de troca de móveis/ambientes e regressão, publicar ambiente de homologação isolado, modelar persistência e autorizações.
